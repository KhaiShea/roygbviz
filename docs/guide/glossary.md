# Glossary

Plain-language definitions.

| Term | Meaning |
|---|---|
| **Aesthetic (aes)** | A link from a data column to a visual property such as position, colour or size. |
| **Alpha** | Transparency, from 0 (invisible) to 1 (solid). |
| **Annotation** | Text, often with an arrow, pointing at something in the plot. |
| **Artist** | Anything matplotlib draws: a line, text, a patch. |
| **Aspect ratio** | Width divided by height. |
| **Axes** | One plot area. Not the plural of axis (matplotlib's naming is confusing). |
| **Axis** | One number line with ticks and labels. |
| **Bin** | A range of values counted together in a histogram. |
| **Categorical data** | Labels without a number scale, such as model names. |
| **Colormap (cmap)** | A smooth range of colours used for numbers. |
| **Confidence interval** | A range that would contain the true value in a stated share of repeats (often 95%). |
| **Constrained layout** | Matplotlib's automatic spacing so labels do not overlap. |
| **Coord** | How positions are placed on the page. |
| **DPI** | Dots per inch. How many pixels make an inch when saving a raster file. |
| **Diverging scale** | Two hues with a neutral middle, for values above and below a midpoint. |
| **ECDF** | Empirical cumulative distribution function: the share of data at or below each value. |
| **Facet** | A panel in a set of small multiples. |
| **Figure** | The whole canvas. |
| **Formatter** | Decides what a tick label says. |
| **Geom** | The shape drawn for data (point, line, bar). |
| **Glyph** | One drawn character in a font. |
| **Grammar of graphics** | A system describing charts as data, aesthetics, geoms, stats, scales, coords, facets and themes. |
| **Jitter** | A small random nudge to stop points overlapping. |
| **Latency** | Delay. In speech pipelines, time before the reply is heard. |
| **Legend** | A key explaining colours or markers. |
| **Locator** | Decides where ticks go. |
| **Log scale** | An axis where each step multiplies by a constant, so equal distances mean equal ratios. |
| **Marker** | A symbol at a data point. |
| **MOS** | Mean opinion score, listeners' rating from 1 to 5. |
| **Overplotting** | So many points that they hide each other. |
| **Pareto front** | Options that no other option beats on every measure. |
| **Patch** | A filled shape such as a circle or rectangle. |
| **Position adjustment** | What to do with overlapping marks: stack, dodge, fill, jitter. |
| **rcParams** | Matplotlib's global settings dictionary. |
| **Raster** | An image made of pixels (PNG, JPEG). |
| **Scale** | The rule turning data values into positions or colours. |
| **Sequential scale** | One hue from light to dark, for magnitude. |
| **Small multiples** | Many small charts with the same axes. |
| **Spine** | A line along the edge of an Axes. |
| **Stat** | A calculation applied to data before drawing. |
| **STT / LLM / TTS** | Speech to text, large language model, text to speech: the three stages of a cascade. |
| **Theme** | The non-data look of a chart. |
| **Tidy data** | A table with one row per observation and one column per variable. |
| **Tick** | A small mark showing a position on an axis. |
| **Transform** | The mapping between coordinate systems (data, axes, figure, pixels). |
| **Vector** | Graphics stored as shapes (PDF, SVG), sharp at any size. |
| **WER** | Word error rate, the share of words a recogniser gets wrong. |
